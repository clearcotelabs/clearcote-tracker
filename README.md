## How we test

Each website is opened in a fresh Clearcote hosted cloud browser, logged out, on its public home page or a public page such as a company or product page. A website counts as working when the site's own page appears with nothing in the way, confirmed on a screenshot. **Last checked** is the date of that check; *Oct 2026* means the status comes from our first round of tests in October 2026 and has not been re-confirmed since. Websites change often, so a status can change between checks.

We only load public pages: no logins, no accounts, no purchases, and no data from the sites is stored or published here.

## Remove a website

If you run a listed website and want it removed from this list, [open an issue](https://github.com/clearcotelabs/clearcote-tracker/issues) or email [info@clearcotelabs.com](mailto:info@clearcotelabs.com). We remove it within 7 days.

## How we test

Each site is opened in fresh Clearcote hosted browsers with standard settings. A site counts as **loads** when the real page appears, fully rendered, with nothing in the way. If every attempt in a test round ends on an error, a refusal or a verification page instead, it is listed as **doesn't load yet**.

We test public pages only: no logins, no accounts, no purchases. Results reflect our tests at the time of checking. Websites change often, so a status can change between checks.
